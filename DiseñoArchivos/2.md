# 2. Trabajo práctico

## 2.1. Propuesta de infraestructura

A partir de las necesidades específicas de Distributions-Líder, la infraestructura se organiza de la siguiente manera:

*   **Redes o zonas (VLANs):**
    *   **VLAN 10 DMZ:** Aloja el portal web público separado de la red principal para evitar infecciones derivadas de los múltiples dispositivos del área de reparaciones[cite: 1, 5].
    *   **VLAN 20 INTERNA:** Conecta a los empleados del sótano (Almacén), primera planta (Montaje) y segunda planta (Admin/Marketing), permitiendo compartir el inventario y los manuales técnicos de forma fluida[cite: 1, 4].
    *   **VLAN 30 MONITOREO:** Red aislada para controlar el estado de los servidores y garantizar la disponibilidad del portal web de clientes[cite: 1, 5].
    *   **VLAN 40 BASE DE DATOS:** Aislamiento estricto para proteger los datos de facturación e inventario corporativo[cite: 1, 5].
*   **Servidores y servicios principales:**
    *   **Rancher y Nginx Proxy Manager (DMZ):** Gestionan y exponen de forma segura el portal para que las pymes clientes puedan comprar equipos o consultar el estado de sus incidencias[cite: 1, 4, 5].
    *   **LDAP (Directorio):** Controla de forma centralizada qué empleados tienen acceso a la facturación (Administración), a las redes (Marketing) o al software de despliegue (Montaje)[cite: 1, 5].
    *   **Servidor de Almacenamiento/Automatización (Scripts):** Ejerce de repositorio centralizado para ISOs, manuales de reparación y automatiza las instalaciones de SO por red (PXE) para agilizar el trabajo en Montaje[cite: 1, 4, 5].
    *   **MariaDB:** Base de datos general que respalda las operaciones del portal web[cite: 1, 5].
    *   **Stack de Monitoreo (Zabbix, OpenSearch, T-Pot):** Controla el hardware, analiza logs y protege la red mediante señuelos (honeypot) contra ataques[cite: 1, 5].
*   **Dispositivos de red:**
    *   **OPNsense (Shield):** Firewall perimetral e inter-VLAN que protege los sistemas, filtra el tráfico y proporciona asignación IP dinámica (DHCP) para los equipos de los empleados y los dispositivos rotativos de la zona de reparaciones[cite: 1, 5].
    *   **Router WAN:** Conexión principal a Internet e interconexión con los servicios de AWS[cite: 1].
*   **Ubicación de equipos:** Los equipos de usuario se distribuyen físicamente entre el sótano (4 empleados), la 1ª planta (8 empleados) y la 2ª planta (8 empleados)[cite: 4]. Los 2 administradores técnicos operan la infraestructura desde la VLAN 20[cite: 1, 4].
*   **Accesibilidad desde Internet:** Únicamente el portal web de clientes a través de Nginx y el puerto VPN seguro gestionado por OPNsense[cite: 1, 5].
*   **Integración VPN:** Permite el teletrabajo a los empleados de oficina y facilita la gestión remota de servidores a los administradores de sistemas[cite: 1, 5].
*   **Servicios Cloud:** Conexión a AWS S3 para externalizar copias de seguridad de las configuraciones de los clientes, inventario y contabilidad[cite: 1, 5].
*   **Justificación:** Esta segmentación cumple estrictamente con el análisis de necesidades tecnológicas: aísla los equipos de prueba de la red principal, centraliza el almacenamiento departamental, asegura la base de datos y automatiza tareas rutinarias (PXE) sin comprometer la seguridad[cite: 4, 5].

## 2.2. Diagrama de la infraestructura

El diagrama de red diseñado representa fielmente la solución tecnológica para Distributions-Líder. Muestra el acceso a Internet y el túnel VPN terminando directamente en el firewall OPNsense, el cual segmenta de forma segura el tráfico hacia las cuatro zonas (DMZ, Interna, Monitoreo y Base de Datos)[cite: 1, 3, 5]. Se visualiza la ubicación lógica de los servidores (Nginx, Rancher, LDAP, MariaDB y el stack de seguridad), las estaciones de trabajo de los distintos departamentos y la integración hacia AWS Cloud para garantizar la redundancia del inventario y la contabilidad[cite: 1, 4, 5].
